# कलाspace — Online Portfolio for Artists and Creatives (CSE326 Project)

A clean, beginner-friendly web application built strictly using **CSE326 Units 1–6** (Pure HTML5, Pure CSS3, and Pure Vanilla JavaScript — no external frameworks or libraries).

## Course Unit Mapping (Viva Quick Reference)
- **Unit 1 (HTML Fundamentals):** HTML5 boilerplate, headings, paragraphs, lists, links, images, SEO meta tags, and inline `<svg>` artwork graphics.
- **Unit 2 (Semantic HTML & Forms):** Semantic landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`), accessibility (`skip-link`, `aria-label`, `aria-live`, `<label for>`), forms with validation attributes, and an HTML `<table>` for Admin Moderation.
- **Unit 3 (CSS):** CSS Variables (`:root` for Plum & Rose Quartz Light theme + `body.dark-theme` for Obsidian & Gold Dark theme), Box Model, Flexbox (header, list view, cards), CSS Grid (responsive gallery & forms), `:hover` / `:focus-visible` pseudo-classes, transitions, and `@media` responsive queries.
- **Unit 4 (JavaScript Fundamentals):** `const`/`let`, objects, arrays, functions, arrow functions, conditionals (`if/else`, ternary).
- **Unit 5 (Interactive Web Development):** DOM manipulation (`querySelector`, `createElement`, `classList`), `addEventListener` event delegation, array higher-order methods (`filter`, `map`, `find`, `sort`, `reduce`), Regular Expressions (email & year validation), `Date`, `FileReader`, and `localStorage`.
- **Unit 6 (Web App Development & Deployment):** `try/catch` error handling around `localStorage`, `console.log`/`console.warn` debugging, modular file separation (`index.html`, `style.css`, `script.js`), and GitHub Pages deployment readiness.

## How to Deploy on GitHub Pages (Unit 6)
1. Create a new public repository on GitHub (e.g., `kalaspace-portfolio`).
2. Upload all project files (`index.html`, `style.css`, `script.js`, `README.md`, and all `.jpg` artwork/logo images) (or push with `git add .`, `git commit -m "Initial commit"`, `git push`).
3. Go to **Settings -> Pages -> Build and deployment -> Branch: main -> Save**.
4. Your live website URL will appear at `https://<your-username>.github.io/kalaspace-portfolio/`.
